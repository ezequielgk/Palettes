# Palettes

A collection of color palettes in JSON format, with a web gallery to browse them, copy them, and try them out as a theme.

## Structure

Each palette lives in its own folder, with a `.json` file named exactly like the folder.

## Gallery

Open `index.html` (or the repo's GitHub Pages site) to see all the palettes. From there you can copy colors as HEX, RGB or HSL, export them as CSS or JSON, and apply any palette as the theme of the site itself.

## Adding a palette

1. Create a folder named after the palette.
2. Inside it, add a `.json` file with the same name as the folder.
3. That's it: it shows up in the gallery automatically.
